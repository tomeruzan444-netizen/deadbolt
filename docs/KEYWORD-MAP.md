# Keyword Map: Deadbolt Fixers

This file is the single source of truth for which page owns which search query. **One page = one main keyword = one search intent.** Before creating any new page, check this map. If the new page's keyword or intent overlaps an existing row, change the angle or extend the existing page instead.

Columns:
- **Main keyword**: must appear exactly as written in the H1, title tag, meta description, first paragraph, at least one H2, and 5+ times in body prose (see `CONTENT-GUIDE.md` section 4).
- **Intent**: T = transactional (wants to hire), C = commercial investigation (comparing, pricing), I = informational (wants to learn/fix), N = navigational.
- **Secondary keywords**: natural variations and related terms to cover semantically. Never force these.
- **Owns (FAQ territory)**: the sub-questions this page answers. Other pages may *mention* these topics in a sentence and link here, but may not answer them in depth or repeat them as FAQs.
- **Must not compete with**: the closest neighbor pages and how this page stays different.
